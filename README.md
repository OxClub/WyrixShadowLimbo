# Shadow Limbo: The Lost Sister (WYRIX)

Complete 2D Narrative Puzzle-Platformer Android Game built in Native Kotlin with:
- **8 Full Story Chapters** (from Awakening in the Mist to Reunion with sister Aria)
- **Complete UI Flow:** Title Cover Screen, Chapter Select (with auto-save), Pause/Resume Menu, Audio Mute Toggle
- **Physics & Puzzle Mechanics:** Pushable crates, pressure plates, opening iron gates, spinning sawblades, bear traps
- **Responsive Multi-Touch Controls:** Left (`◀`), Right (`▶`), and Jump (`▲`) buttons
- **Original Multi-Track Atmospheric Audio:** 8 unique chapter ambient tracks + 5 real sound effects
- **Adaptive App Icon (`ic_launcher`):** Ready for Google Play Console

## Build via GitHub Actions
1. Extract this ZIP and push to your GitHub repository (`main` branch).
2. GitHub Actions will automatically compile `app-release.aab` (~118 MB) and `app-debug.apk` (~118 MB).
